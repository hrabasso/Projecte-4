# P03: Kanban del projecte 🧮

## 📌 Objectiu
Gestionar i fer el seguiment del projecte utilitzant la metodologia **Kanban**, garantint que totes les tasques del Product Backlog s’organitzen i monitoritzen correctament.

## 🧩 Descripció
Com en projectes anteriors, la metodologia Kanban és vital pel bon funcionament del projecte. A partir del **Product Backlog** proporcionat, heu de:
- Registrar les tasques realitzades.
- Actualitzar l’estat de cada tasca de manera regular.
- Fer un seguiment constant de les vostres realitzacions.

Cada setmana es farà una revisió de l’estat del **Planner**, així que és molt important no deixar la gestió del Kanban per última hora.
